# 0007. «Любимое» — статус библиотеки

- **Статус:** принято
- **Дата:** 2026-11-26
- **Заменяет:** пункт 3 решения [0006-library-first.md](0006-library-first.md) в части `favorite`
- **Связано:** [0004-first-source-remanga.md](0004-first-source-remanga.md), [0005-second-source-rumix.md](0005-second-source-rumix.md)

## Контекст

Отдельный флаг `favorite` создавал вторую ось состояния: тайтл мог быть одновременно «Любимым» и «Читаю». В интерфейсе это дублировало управление статусом — отдельная вкладка библиотеки, отдельная кнопка на странице тайтла, отдельный пункт в читалке, отдельный счётчик и отдельное поле в API. Для закрытого каталога такая вторая ось ничего не добавляет.

## Решение

1. `favorite` — значение CHECK статуса библиотеки наряду с «Читаю», «Буду читать» и остальными.
2. Колонка `library.favorite` удалена миграцией 0006. Существующие `favorite = 1` переносятся в `status = 'favorite'` (флаг важнее прежнего статуса), остальные записи сохраняют статус.
3. `GET /api/library` больше не принимает `favorite`; счётчик переехал в `counts.statuses.favorite`. `PUT /api/library/{title_id}` принимает только `{ status, score }`.
4. UI: статус выбирается одним Select под обложкой; «Любимое» — обычная вкладка статуса в библиотеке; в читалке свои закладки и статус живут в одном меню.

## Последствия

- Нельзя одновременно «Любимое» и «Читаю» — это осознанно: одно состояние вместо двух.
- Миграция 0006 пересобирает `library` из-за CHECK: состав `library_tab_items` временно сохраняется в промежуточной таблице и возвращается после пересборки, иначе каскадный FK стёр бы закладки.
- Старые клиенты, присылающие `favorite`, не получают ошибку (неизвестное поле игнорируется), но флаг больше ни на что не влияет.

## Альтернативы

| Вариант | Почему отклонён |
|---|---|
| Оставить флаг и добавить статус | Две оси снова расходятся; UI дублирует управление статусом |
| Отдельная сущность «тег любимого» | Для закрытого каталога лишняя сущность; статуса достаточно |
| Не мигрировать существующие флаги | Пользователь потерял бы выставленное «Любимое» без следа |
