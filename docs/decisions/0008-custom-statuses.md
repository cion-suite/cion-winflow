# 0008. Свои закладки — это статусы

- **Статус:** принято
- **Дата:** 2026-11-26
- **Заменяет:** мультивыбор своих закладок из [0006-library-first.md](0006-library-first.md)
- **Связано:** [0004-first-source-remanga.md](0004-first-source-remanga.md), [0007-favorite-status.md](0007-favorite-status.md)

## Контекст

Свои закладки были отдельной структурой many-to-many (`library_tabs` + `library_tab_items`): тайтл мог одновременно быть в нескольких закладках и иметь встроенный статус. В интерфейсе это давало две группы управления — «Статус» и «Свои закладки» — и не позволяло трактовать закладку как статус. По смыслу своя закладка — это тот же статус, только пользовательский; отдельная сущность здесь лишняя.

## Решение

1. Своя закладка — ещё один статус; у тайтла ровно один статус: встроенный или своя закладка.
2. `library.custom_tab_id` (nullable, FK на `library_tabs`, `ON DELETE SET NULL`) перекрывает `library.status`.
3. `library_tab_items` удалена миграцией 0007. При миграции из нескольких закладок остаётся первая по порядку вкладок.
4. `PUT /api/library/{title_id}` принимает `custom_tab_id`; отдельный `PUT /api/library/{title_id}/tabs` удалён.
5. В Select статуса свои закладки идут после встроенных, за разделителем; в библиотеке — обычные вкладки после статусов.
6. Встроенные счётчики и фильтр `status` не учитывают записи с `custom_tab_id`; счётчик своей закладки — в `LibraryTab.count`.

## Последствия

- Нельзя одновременно «Читаю» и «Своя закладка» — это и есть смысл одного статуса.
- Удаление своей закладки возвращает сохранённый встроенный статус, а не теряет состояние.
- Мультивыбор убран; при миграции лишние членства теряются (остаётся первая закладка).
- Своих закладок по-прежнему не больше трёх, имя уникально у пользователя.

## Альтернативы

| Вариант | Почему отклонён |
|---|---|
| Оставить many-to-many | Две оси состояния и отдельное понятие, вопреки требованию |
| Хранить свой статус в текстовом `status` | Пришлось бы ломать CHECK и валидацию; FK на `library_tabs` надёжнее |
| Удалять тайтл вместе с закладкой | Пользователь терял бы запись библиотеки; выбран возврат встроенного статуса |
