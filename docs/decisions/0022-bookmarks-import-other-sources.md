# 0022. Импорт закладок ищет исчезнувшие тайтлы на других источниках

Дата: 2026-11-28
Статус: принято

## Контекст

Remanga удаляет тайтлы и меняет `dir`. Импорт закладок завершался ошибкой
`source_not_found` для каждого такого тайтла, хотя произведение есть на
RuMix или Mangamir. Пользователь терял статус и прогресс, хотя мог читать
тайтл на другом подключённом источнике.

## Решение

Если импорт по `dir` вернул «нет на источнике» (`source_not_found`,
`source_invalid_external_id` или `source_auth_maybe_required`), сервер:

1. повторяет поиск по точному названию на том же источнике (как раньше —
   `dir` мог устареть, а название осталось);
2. ищет точное нормализованное название на остальных включённых источниках
   с `Search` + `Chapters` в порядке приоритета их языка, резолвя учётку
   инициатора для каждого;
3. импортирует первое совпадение через `source_admin::import` с
   `auto_link=true` (автослияние привяжет запись к уже существующей
   карточке) и применяет к найденному тайтлу статус и прогресс закладки.

Ошибки поиска или импорта отдельного источника логируются и не отменяют
остальные. Если ни один источник не дал результата, возвращается первая
содержательная ошибка fallback-поиска (rate limit, сеть, auth) — иначе
исходная ошибка Remanga: `source_not_found` либо
`source_auth_maybe_required` (подсказка «возможно, нужен аккаунт»
сохраняется). Поиск ограничен общим таймаутом, чтобы медленный источник
не держал слот импорта.

## Причины

- `dir` Remanga нестабилен; название — единственный переносимый
  идентификатор закладки.
- Тот же код импорта переиспользуется: автослияние по названию не создаёт
  дубль, если тайтл уже есть в библиотеке из другого источника.
- Принимается только точное совпадение основного или альтернативного
  названия — иначе можно привязать чужое произведение.

## Альтернативы

- **Создавать пустой тайтл из закладки.** Отклонено: карточка без глав и
  привязок бесполезна и засоряет каталог.
- **Просить пользователя добавить каждый тайтл вручную.** Отклонено:
  теряется смысл импорта закладок.
- **Фильтровать кандидатов по языку тайтла.** Невозможно: тайтла ещё нет.
  Поэтому порядок задаёт приоритет языка источника, а совпадение названия
  остаётся строгим.

## Последствия

- Ошибки импорта больше не содержат тайтлы, найденные на другом источнике.
- `source_discovery::find_external_id` — общий поиск точного названия для
  этого сценария; тест `bookmarks_import_falls_back_to_another_source_when_title_is_gone`
  проверяет путь на локальном двойнике Remanga и fixture-источнике.
