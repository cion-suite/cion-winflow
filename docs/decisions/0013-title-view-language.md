# 0013. Язык просмотра тайтла

Дата: 2026-11-27
Статус: принято

## Контекст

Страница тайтла всегда показывала один общий список глав, а приоритеты
источников выбирались по `titles.lang` — языку метаданных. Если к тайтлу
привязаны переводы разных языков, читатель не может выбрать, какой из них
смотреть и читать: список смешивает главы, а `content` берёт вариант по
глобальному приоритету. Менять `titles.lang` ради этого нельзя — это
метаданные тайтла, которые участвуют в слиянии описания и в пересчёте
preferred.

Две колонки по языкам в настройках оказались неудачной заменой: колонка
без связок выглядит пустой, а остальные вкладки всё равно смешивают
переводы.

## Решение

Ввести **язык просмотра** — состояние страницы тайтла, отдельное от
`titles.lang`.

- Переключатель показывается, только если у тайтла есть **включённые**
  источники двух и более языков (`sources[].lang` из дескрипторов). Язык хранится в URL
  (`/title/{id}?lang=`) и в `localStorage` по id тайтла; URL важнее
  сохранённого выбора. Это согласуется с текущими настройками в браузере;
  серверный профиль появится позже.
- `GET /api/titles/{id}?lang=` фильтрует главы по языку источника-варианта,
  ранжирует источники по приоритетам этого языка и выбирает вариант из
  него же. Язык, которого нет среди привязанных источников, игнорируется:
  устаревшая ссылка не должна опустошать страницу.
- `GET /api/titles/{id}/chapters/{chapter_key}/content?lang=` выбирает
  вариант только из источников выбранного языка. Fallback между языками
  не делается: подмена перевода в читалке незаметна и хуже, чем ошибка;
  внутри одного языка fallback по источникам сохраняется.
- Нумерация главы по-прежнему берётся у канонического варианта (так
  работают связки-диапазоны); меняются только выбранный/доступный вариант
  и его источник.
- Карточка «Источники», связки-диапазоны, диалоги и поиск расхождений
  ограничены выбранным языком. Глобальные ручные пары (`source_entry_id IS NULL`)
  языка не имеют и показываются всегда. «О тайтле» и `titles.lang` не меняются.
- На вкладке «Настройки» правая колонка сетки остаётся пустой, но занимает
  место: ширина совпадает с главами и «О тайтле».

## Последствия

- Читалка и переходы несут `lang`; прогресс остаётся по каноническому
  ключу, поэтому связанные алиасами переводы делят прогресс.
- Тайтл с несколькими языками создаётся не автоматически: `auto_link_sources`
  по-прежнему привязывает только копии того же языка. Перевод другого
  языка можно добавить через `discover/add` (привязка по названию) или
  админский API.
- Пока все адаптеры объявлены `lang: "ru"` (включая MangaMir), переключатель
  скрыт; он оживёт с первым англоязычным адаптером.
- Выбор в `localStorage` — на браузер, а не на пользователя; при появлении
  профиля он переедет на сервер.

## Альтернативы

- **Менять `titles.lang` при переключении.** Отклонено: это язык метаданных,
  он участвует в слиянии описания и пересчёте preferred, а выбор должен
  быть у читателя.
- **Две фиксированные колонки «Русские/Англоязычные».** Отклонено: пустая
  колонка занимает половину ширины, а главы и читалка всё равно смешивают
  переводы.
- **Серверная настройка per-user сразу.** Отложено до профиля; сейчас
  настройки проекта живут в `localStorage`.
